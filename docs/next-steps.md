# Next steps

Planned additions to the lab:

- [ ] **Supersedence:** deploy an older 7-Zip, then a newer version that supersedes and upgrades it
- [ ] **Dependencies:** Visual C++ Redistributable as a dependency of another app
- [ ] **Required deployment:** an app that installs automatically with a deadline
- [ ] **Uninstall deployment:** remove an app from a collection
- [ ] **Query-based collection:** add clients automatically with `Name like 'WIN%'`
- [ ] **Requirements:** limit an app to Windows 10/11 64-bit
- [ ] **PowerShell script app:** with a registry or file detection method
- [ ] **Software updates:** a Software Update Point (WSUS) and a monthly update group
- [ ] **OS deployment:** boot image, PXE and a task sequence to install Windows
- [ ] **Group Policy:** push the client firewall rules instead of setting them by hand
- [ ] **Co-management with Intune:** connect the lab to Microsoft Intune

App-V is not on the list: Microsoft retired it (client support ended April 2026), and MSIX is the modern replacement.
